eBay出品のアパレルルール

アパレルは必須項目を全部そろえないと
出品できない

2026年9月から服・靴・帽子・バッグで「902:ebay更新エラー」が増えています。原因の多くは、Item Specifics(商品の詳細情報)の必須項目が埋まっていないことと、Size と Size Type の組み合わせ違反です。このページはeBay公式データ(2026年9月2日調べ)をもとにした早見表です。

いちばん大事な3つの決め事

  1. Size Type は常に Regular にする。大きいサイズ専門で出品する場合以外は、他の値を選ばない。
  2. Size は文字サイズ S・M・L・XL だけを使う。タグに数字が書いてあっても、実寸から文字サイズに読み替える。cm・Free・裸の数字・S/M のような複合表記はそのまま使わない。One Size は帽子・小物だけで使う。
    例外はジーンズ・パンツだけ。ウエストのインチ数値（タグの W30 なら 30、実寸 cm は 2.54 で割って最も近い値）を Size にする。Regular で通るのはレディース 23〜33、メンズジーンズ 24〜32 と 34〜50 の偶数、メンズパンツ 26〜32 と 34〜50 の偶数。範囲外は文字サイズに読み替える。あわせて Waist Size（任意）に 30 in、メンズは必須の Inseam に 32 in を入れる。
  3. 必須項目に NA を入れない。Department は Men か Women のどちらかにする。Color は公式17色から選ぶ。Brand は不明なら Unbranded にする。

●エラー文から原因をさがす

出てきたエラー文の型に近いものを探してください。

エラー文の型意味直し方
"○○" is not a valid value for Size Type
"○○" is not a valid value for Size		 値がリストにない カテゴリ別カードの語に直す(Size Type に L を入れている例が多い)
"Regular" is not a valid Size Type for the Size "40" Size と Size Type の組み合わせ違反 レディースの裸の数字は Plus 扱いなので EU 40 / IT 40 と書くか、実寸から S/M/L に読み替えて Regular にする
必須項目未入力・NA 必須項目の欠落 カードの必須項目を全部埋める

●Size Type とは

Size Type は体型区分であって、サイズそのものではありません。服のカテゴリだけにある項目で、帽子・バッグ・靴にはありません。

レディースは6値: Regular / Plus / Petites / Tall / Juniors / Maternity。メンズは2値: Regular / Big & Tall。

表記は頭文字を大文字にします。Petites は複数形です。Big & Tall は&の前後に半角スペースを入れます。既定は Regular です。

●Size と Size Type の組み合わせ

Size Type を Regular にしたときに、Size 欄に書ける言葉の範囲です。

項目レディース Regularメンズ Regular
文字サイズ3XS〜XL、2XL2XS〜XL、2XL
裸の数字0〜16 は米国サイズで可。18以上は Plus 専用。ジーンズ・パンツはウエスト 23〜33 が Regular で可28〜50 は可。52以上は Big & Tall 専用。ジーンズはウエスト 24〜32・34〜50（偶数）、パンツは 26〜32・34〜50（偶数）が Regular で可
国別表記EU 32〜50 / IT 36〜54 / FR 32〜50 / UK 4〜22EU・IT・FR 42〜60
One Size可可。ただしスーツ 3001・ドレスシャツ 57991 は不可
S/M 等の複合使わない（APIには一部カテゴリで値があるが、eBay公式のサイズ標準化ガイドで「複数の Size を組み合わせた値」は非サポート）使わない（同左）

迷ったら3つの決め事どおり文字サイズ＋Regularにすれば、どのカテゴリでも通ります(28カテゴリ全てで確認済み)。

●カテゴリ別の必須項目

「見落とし注意」は、必須なのに空欄にしがちな項目です。値はカードに書かれた語だけを使ってください。n が多い項目は代表例だけを載せています。

●スキルに追加する時の指示文

eBayのアパレル出品ルールを、翻訳・出品作成のスキルに追加してください。

【3つの決め事】
Size Type は常に Regular にする。大きいサイズ専門で出品する場合だけ例外にする。
Size は文字サイズ S、M、L、XL だけを使う。タグが数字でも実寸から文字に読み替える。cm、Free、裸の数字、S/Mのような複合表記はそのまま使わない。One Size は帽子と小物だけで使う。
例外はジーンズ・パンツ(レディース11554・63863、メンズ11483・57989)だけで、ウエストのインチ数値をSizeにする(タグのW30なら30、実寸cmは2.54で割って最も近い値)。Regularで通る値はレディース23から33、メンズジーンズ24から32と34から50の偶数、メンズパンツ26から32と34から50の偶数。範囲外は文字サイズに読み替える。あわせてWaist Size(任意)に30 in、メンズは必須のInseamに32 inを入れる。
必須項目に NA を入れない。Department は Men か Women のどちらかにする。Color は公式17色から選ぶ。Brand は不明なら Unbranded にする。

【必須項目の埋め方】
アパレル(Clothing, Shoes & Accessories 配下)のカテゴリIDが決まったら、このページ(URL: https://naokijodan.github.io/ebay-size-guide/ )のカテゴリ別カードにある必須項目を全部埋める。値はカードに書かれた語だけを使い、カードに無い語を作らない。

【Size と Size Type の組み合わせ】
文字サイズは、レディースが3XSからXLと2XL、メンズが2XSからXLと2XLまで使える。
裸の数字は、トップス・ワンピース等の米国サイズでは、レディースが0から16は使えるが18以上はPlus専用になる。メンズは28から50が使えるが、52以上はBig & Tall専用になる。ジーンズ・パンツのウエスト数値は上の例外のとおり。
国別表記は、レディースがEU、IT、FR、UKの4種類、メンズがEU、IT、FRの3種類で使える。
One Sizeは、レディース・メンズとも基本的に使えるが、メンズスーツ(3001)とメンズドレスシャツ(57991)では使えない。
S/Mのような複合表記(1つのSize欄に複数サイズ)は、全カテゴリで使わない。eBay公式のサイズ標準化ガイドで「S/M/Lなど複数のSizeを組み合わせた値」は非サポートとされている。

【書き込み後の確認】
書き込みが終わったら、Size Type に文字サイズが入っていないこと、必須項目に NA や空欄が無いことを機械的に確認する。
