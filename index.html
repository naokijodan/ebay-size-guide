eBay出品のサイズ欄ルール

「One Size」が使える場所、
使えない場所

eBayに出品するとき、商品の詳細情報（Item Specifics）の「Size」欄に書いていい言葉は、実はカテゴリごとに決まっています。リストにない言葉を書くと「902:ebay更新エラー」になって出品できません。このページはeBay公式のデータ（2026年9月1日調べ）をもとにした早見表です。

いちばん大事なこと

帽子では「One Size」でOKでしたが、メンズスーツとバッグでは「One Size」は使えません。「迷ったら One Size」というルールを全部のカテゴリに使い回すと、エラーになります。下のカテゴリ別カードで確認してください。

●カテゴリ別の早見表

◎=使える ／ ×=使えない です。

🧢帽子

メンズ 52365 ／ レディース 45230

Size欄は必須One Size ◎S/M・M/L ×

使えるのは XS〜XL、帽子サイズの数字（例 7 1/2）、One Size だけです。

書き方: フリーサイズ・Free・「58cm」などのcm表記・S/M → ぜんぶ One Size に。「7 1/2 / 59.6cm」のような併記は 7 1/2 だけ残します。Adjustable はレディースのみOK（メンズは×）。

👕Tシャツ・トップス

メンズTシャツ 15687 ／ レディーストップス 53159

Size欄は必須One Size ◎S/M・M/L ◎

ここはゆるめです。One Size も、S/M・M/L・L/XL のような表記も、XS〜XLや数字サイズもそのまま使えます。

書き方: フリーサイズだけ One Size に直せばOKです。

🤵スーツ（メンズ）

3001

Size欄は必須One Size ×S/M ×空欄も ×

いちばん厳しいカテゴリです。One Size も複合表記も使えず、空欄にもできません。

書き方: 決められた76種類（2XS〜8XL、数字28〜62、Big系、Tall系、IT・EU・FR表記）の中から、実寸に合うものを必ず選びます。

👩‍💼スーツ（レディース）

63865

Size欄は必須One Size ◎S/M ◎

メンズと違ってこちらはゆるめです。One Size も S/M などもOKです。

🧥コート・ジャケット（メンズ）

57988

Size欄は必須One Size ◎S/M・M/L ×

One Size は使えますが、S/M・M/L のような複合表記は使えません。XS〜XLや数字サイズはOKです。

👜バッグ

レディース 169291 ／ メンズ 52357

Size欄は入れなくてOKOne Size ×

使えるのは Micro / Mini / Small / Medium / Large / Extra Large / Nano の7つだけ。One Size は使えません。

書き方: 迷ったら空欄のままにするのが安全です（もともと必須ではありません）。入れるなら大きさに合わせて Small / Medium / Large などを選びます。

●サイズのほかに必ず入れる項目

ここが空欄でも同じようにエラーになる可能性があります。

  • 洋服のカテゴリ: Size Type（Regular / Big & Tall などから選ぶ）・Department・Brand・Color も必須です。
  • バッグ: Brand・Exterior Material（メンズは Material）・Style・Exterior Color（メンズは Color）・Department が必須です。
  • 共通の約束: 必須の欄に「NA」のような仮の言葉を入れない。実寸のcmはタイトルや説明文に書けば情報は残せます。

●スキルに追加する時の指示文

AIにルールを覚えさせる時は、下の文をそのままコピーして貼り付けてください。

eBayの Item Specifics「Size」のルールを、翻訳スキル（Item Specifics 生成規則）に追加してください。

【原則】
- Size は eBay 公式の許容値のみ使用する。許容値はカテゴリごとに異なるため、「迷ったら One Size」を全カテゴリ共通にしない。リスト外の値（Free / 58cm / 55-61cm / NA 等）は「902:ebay更新エラー」で登録に失敗する（2026-09-01 Taxonomy API 実測）。
- 実寸 cm は Title・Description に残す（情報は失われない）。
- 必須 Item Specifics に「NA」等のプレースホルダを入れない。

【カテゴリ別ルール】
1. 帽子（Men 52365 / Women 45230 / Boys 57884）: 許容値は XS / S / M / L / XL / 帽子サイズ数値（6〜8 1/2、例 7 1/2）/ One Size。Adjustable は Women・Boys のみ可（Men 52365 には無い）。S/M・M/L 等の複合表記は不可。変換: フリーサイズ・Free・単独cm・範囲cm・S/M・M/L → One Size。「7 1/2 / 59.6cm」等の併記 → 7 1/2 のみ。
2. Tシャツ・トップス（メンズTシャツ 15687 / レディーストップス 53159）: One Size 可。S/M / M/L / L/XL / XS/S の複合表記も可。XS〜XL 等の文字サイズ・数値サイズも可。フリーサイズ → One Size。
3. メンズスーツ（Suits & Suit Separates 3001）: One Size 不可。S/M 等の複合表記も不可。Size 必須のため空欄も不可。許容76種（2XS〜8XL / 数値28〜62 / Big 1X〜6X / ST・MT・LT〜6XLT の Tall 系 / IT・EU・FR 表記）から実寸に基づき必ず選ぶ。
4. レディーススーツ（63865）: One Size 可。S/M 等の複合表記も可。
5. メンズコート・ジャケット（57988）: One Size 可。S/M・M/L は不可。
6. バッグ（レディース 169291 / メンズ 52357）: Size は必須ではない。許容値は Micro / Mini / Small / Medium / Large / Extra Large / Nano の7種のみで One Size 不可。判断できなければ Size は空欄にする（無理に入れない）。入れる場合は実寸に応じて Small / Medium / Large 等。

【Size 以外の必須項目】
- 衣類カテゴリ: Size Type（Regular / Big & Tall 等の選択式）・Department・Brand・Color も必須。空欄にしない。
- バッグ: Brand・Exterior Material（メンズは Material）・Style・Exterior Color（メンズは Color）・Department が必須。空欄にしない。
- 上記以外のカテゴリで Size を求められた場合は、リスト外の値を推測で入れず、公式許容値（Taxonomy API getItemAspectsForCategory）を確認してから入れる。

出典: eBay公式 Taxonomy API（getItemAspectsForCategory、アメリカのカテゴリツリー）を2026年9月1日に実測した結果です。子供用（ボーイズ 57884 など）は出品しない方針のため、カードからは省いています。API上ではSize欄は自由入力の扱いですが、EAGLE経由の実際の登録ではリスト外の値がエラーになった実績があります（エラー判定がeBay側かEAGLE側かは未確認）。
